# Indian Banking Transaction Analysis & Interactive Dashboard

## 📌 Project Overview

This project analyzes banking transaction data using Microsoft Excel
to identify transaction trends, regional performance, payment channel
activity, fraud patterns, and transaction status.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- PivotTables
- PivotCharts
- Slicers
- Dashboarding
- Business Insights

## 📊 Dashboard Analysis

The dashboard includes:

- Regional Transaction Volume
- Monthly Transaction Trends
- Transaction Volume by Payment Channel
- Transaction Volume by Branch
- Transaction Type Breakdown
- Fraud Pattern by Region
- Transaction Status Distribution
- Interactive Slicers
- KPI Cards

## 🔍 Key Insights

- Total transactions analyzed: 500
- Fraudulent transactions: 13
- Failed + Reversed transactions: 47
- Regional transaction performance was compared
- Payment modes were analyzed to understand transaction activity
- Monthly trends were analyzed to identify transaction patterns

## 📈 Key Business Questions

- What are the regional and monthly transaction trends?
- Which branches have the highest transaction volume?
- What is the breakdown of transaction types?
- Are there signs of fraudulent transactions?
- Which payment channels have higher transaction activity?
- What proportion of transactions are failed or reversed?
